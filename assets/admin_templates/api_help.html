API 接口使用说明

总览

除 /api/health 外，所有接口都要求鉴权：携带 Authorization: Bearer <你的 Token> 请求头（也可直接用后台登录会话）。 失败统一返回 401；业务错误返回 {error: {code, message}}， 成功返回 {data: ...}。接口地址形如 {{ api_base }}/api/posts。

目录

  • 鉴权与错误格式
  • 文章：/api/posts
  • 说说：/api/moments
  • 分类：/api/categories
  • 附件上传：/api/uploads
  • 统计：/api/stats/summary
  • 备份：/api/backup
  • 健康检查：/api/health
  • MCP 集成（AI 工具）

鉴权与错误格式

所有请求头需携带：

Authorization: Bearer hancic_xxxxxxxxxxxxxxxx

请求体为 JSON（Content-Type: application/json）， 上传接口除外（multipart）。错误响应示例：

{"error": {"code": "unauthorized", "message": "未授权"}}

文章：/api/posts

方法路径说明
GET/api/posts文章列表（分页，可筛选）
POST/api/posts创建文章
GET/api/posts/{id}文章详情
PATCH/api/posts/{id}部分更新（缺失字段不变）
DELETE/api/posts/{id}删除（204）

列表查询参数：page（默认 1）、 page_size（默认 10，最大 100）、status（draft/published）、 category（分类 slug）、tag（标签 slug）。响应 {data: {items: [...], total: N}}。

创建请求体（title/content_md 必填）：

{
  "title": "新文章标题",
  "content_md": "# 正文 Markdown",
  "status": "draft",          // draft | published，默认 draft
  "excerpt": "摘要（可选）",
  "slug": "custom-slug",      // 可选，缺省自动生成
  "category_id": 1,           // 可选，分类 id
  "tags": ["标签1", "标签2"]  // 可选
}

更新（PATCH）：只传要改的字段； "category_id": null 清空分类、"excerpt": null 清空摘要。

curl 示例：

curl -X POST {{ api_base }}/api/posts \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"title":"你好","content_md":"正文","status":"published"}'

说说：/api/moments

方法路径说明
POST/api/moments发布说说（201）
DELETE/api/moments/{id}删除说说（204）

发布请求体：content 必填（非空字符串）， attachment_ids 可选（附件 id 数组，需来自 /api/uploads）。

curl -X POST {{ api_base }}/api/moments \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"content":"今天也是好天气","attachment_ids":[1,2]}'

分类：/api/categories

方法路径说明
GET/api/categories全量分类
POST/api/categories创建分类（201）
PATCH/api/categories/{id}更新（缺失字段沿用现值）
DELETE/api/categories/{id}删除（204，关联文章置为未分类）

创建/更新请求体：name 必填（≤5 字）， slug 可选（缺省按名称生成），sort_order 可选（默认 0）； slug 冲突返回 409。

附件上传：/api/uploads

multipart 表单上传，字段名 files，支持多文件； 成功返回 {data: [{id, path, orig_name, mime, size, kind}]}。 返回的 id 可用于说说 attachment_ids 或文章正文引用 path。

curl -X POST {{ api_base }}/api/uploads \
  -H "Authorization: Bearer $TOKEN" \
  -F "files=@/path/to/image.png"

统计：/api/stats/summary

阅读汇总（总量 + 每日趋势）。可选查询参数 from/to（格式 YYYY-MM-DD，UTC 日期边界）。

curl "{{ api_base }}/api/stats/summary?from=2026-08-01&to=2026-08-13" \
  -H "Authorization: Bearer $TOKEN"

备份：/api/backup

全量备份 zip 下载（数据库 + 配置 + 上传 + 主题）， Content-Type: application/zip。适合 CI / 运维脚本定时拉取。

curl -o backup.zip {{ api_base }}/api/backup -H "Authorization: Bearer $TOKEN"

健康检查：/api/health

存活探针，无需鉴权。返回 {"data": {"status": "ok"}}。

MCP 集成（AI 工具）

本博客附带一个 MCP server（项目 mcp/ 目录， Python + FastMCP 实现），把上述 REST 接口包装为 15 个 MCP 工具，供 Claude Code / Codex / Kimi Code 等 AI 客户端直接调用—— 让 AI 能查文章、发文章、写说说、管理分类、上传附件、下载备份，无需手写 HTTP 请求。

准备：安装依赖并确认环境变量：

cd mcp && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
# 环境变量
HANCIC_API_TOKEN=本页生成的 Token
HANCIC_BASE_URL=https://hancic.site   # 反向代理场景填代理后的公开地址（含子路径）

接入 Claude Code：

claude mcp add hancic -- \
  env HANCIC_API_TOKEN=你的token HANCIC_BASE_URL=https://hancic.site \
  python /path/to/hancic-blog/mcp/hancic_mcp.py

接入 Codex / Kimi Code：在客户端 MCP 配置（或项目级 .mcp.json）注册同一命令：

{
  "mcpServers": {
    "hancic": {
      "command": "python",
      "args": ["/path/to/hancic-blog/mcp/hancic_mcp.py"],
      "env": {
        "HANCIC_API_TOKEN": "你的token",
        "HANCIC_BASE_URL": "https://hancic.site"
      }
    }
  }
}

工具清单：读（list_posts / get_post / list_categories / get_stats / get_backup / get_health）；写（create_post / update_post / delete_post / create_moment / delete_moment / create_category / update_category / delete_category / upload_attachment）。

注意：token 具备写权限（可删除内容、下载全量备份）。 给 AI 工具使用时请妥善保管；MCP server 详细说明见仓库 mcp/README.md。
