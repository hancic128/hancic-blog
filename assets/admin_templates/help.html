总览

除 /api/health 外，所有接口都要求鉴权：携带 Authorization: Bearer <你的 Token> 请求头（也可直接用后台登录会话）。 失败统一返回 401；业务错误返回 {error: {code, message}}， 成功返回 {data: ...}。接口地址形如 {{ api_base }}/api/posts。

鉴权与错误格式

所有请求头需携带：

Authorization: Bearer hancic_xxxxxxxxxxxxxxxx

请求体为 JSON（Content-Type: application/json）， 上传接口除外（multipart）。错误响应示例：

{"error": {"code": "unauthorized", "message": "未授权"}}

文章：/api/posts

方法路径说明
GET/api/posts文章列表（分页，可筛选）
POST/api/posts创建文章
GET/api/posts/{id}文章详情
PATCH/api/posts/{id}部分更新（缺失字段不变）
DELETE/api/posts/{id}删除（204）

列表查询参数：page（默认 1）、 page_size（默认 10，最大 100）、status（draft/published）、 category（分类 slug）、tag（标签 slug）、type （post 普通文章〔缺省〕/ page 独立页面 / all 全部）。 响应 {data: {items: [...], total: N}}。

创建请求体（title/content_md 必填）：

{
  "title": "新文章标题",
  "content_md": "# 正文 Markdown",
  "status": "draft",          // draft | published，默认 draft
  "post_type": "post",        // post 文章 | page 独立页面，默认 post
  "excerpt": "摘要（可选）",
  "slug": "custom-slug",      // 可选，缺省自动生成
  "category_id": 1,           // 可选，分类 id
  "tags": ["标签1", "标签2"]  // 可选
}

更新（PATCH）：只传要改的字段（含 post_type）； "category_id": null 清空分类、"excerpt": null 清空摘要。

另有 POST /api/posts/{id}/timestamps：白名单回填 published_at（三态：缺失不变 / null 清空 / RFC3339 设值）与 updated_at（RFC3339，非空），至少传一个。

curl 示例：

curl -X POST {{ api_base }}/api/posts \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"title":"你好","content_md":"正文","status":"published"}'

说说：/api/moments

方法路径说明
GET/api/moments说说列表（分页 + 筛选）
POST/api/moments发布说说（201）
GET/api/moments/{id}说说详情（含附件）
PATCH/api/moments/{id}部分更新（正文 / 附件）
DELETE/api/moments/{id}删除说说（204）

列表查询参数：page（默认 1）、 page_size（默认 10，最大 100）、q（正文关键词）、 month（YYYY-MM）、order（asc/desc，按时间）。响应 {data: {items: [...], total: N}}。

发布请求体：content 必填（非空字符串）， attachment_ids 可选（附件 id 数组）。更新（PATCH）为部分更新： content / attachment_ids 只更提供的字段（attachment_ids 传数组即 整体替换，[] 清空附件）。

curl -X POST {{ api_base }}/api/moments \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"content":"今天也是好天气","attachment_ids":[1,2]}'

分类：/api/categories

方法路径说明
GET/api/categories全量分类
POST/api/categories创建分类（201）
PATCH/api/categories/{id}更新（缺失字段沿用现值）
DELETE/api/categories/{id}删除（204，关联文章置为未分类）

创建/更新请求体：name 必填（≤5 字）， slug 可选（缺省按名称生成），sort_order 可选（默认 0）； slug 冲突返回 409。

标签：/api/tags

方法路径说明
GET/api/tags全量标签（含各标签文章数）
POST/api/tags创建标签（同名幂等返回既有）
DELETE/api/tags/{id}删除标签（204，关联文章不受影响）

创建请求体：name 必填（≤5 字）。标签按 slug 去重， 同名创建返回既有记录（幂等），不会重复建标签。

专栏：/api/columns

方法路径说明
GET/api/columns全量专栏（含文章数）
POST/api/columns创建专栏（name ≤8 字）
POST/api/columns/reorder专栏排序（body: ids 数组，按序重写）
PATCH/api/columns/{id}更新名称/描述（slug 创建后不改）
DELETE/api/columns/{id}删除专栏（204，文章变为无专栏）
GET/api/columns/{id}/posts专栏下已发布文章列表
POST/api/columns/{id}/posts把文章加入专栏
POST/api/columns/{id}/posts/reorder专栏内文章排序（body: ids 数组）
DELETE/api/columns/{id}/posts/{post_id}把文章移出专栏（204，文章不删）

点赞：/api/likes

方法路径说明
GET/api/likes/status查询点赞状态（无需鉴权）
POST/api/likes/toggle切换点赞（公开端点）

附件上传：/api/uploads

multipart 表单上传，字段名 files，支持多文件； 成功返回 {data: [{id, path, orig_name, mime, size, kind}]}。 返回的 id 可用于说说 attachment_ids 或文章正文引用 path。

curl -X POST {{ api_base }}/api/uploads \
  -H "Authorization: Bearer $TOKEN" \
  -F "files=@/path/to/image.png"

附件库列表（GET /api/attachments）：查询参数 kind（image/video/file，缺省全部）、q（文件名关键词）、 order（asc/desc）、page / page_size。 返回 {data: {items: [{id, kind, orig_name, mime, size, url, created_at}], total}}； url 为前台公开静态地址，可直接用于正文/说说引用。

curl "{{ api_base }}/api/attachments?kind=image&page_size=20" \
  -H "Authorization: Bearer $TOKEN"

删除附件（DELETE /api/attachments/{id}）： 删除磁盘文件与数据库记录，成功 204。

统计：/api/stats

GET /api/stats/summary 阅读汇总（总量 + 每日趋势）。可选查询参数 from/to（格式 YYYY-MM-DD，站点时区日期边界）。

curl "{{ api_base }}/api/stats/summary?from=2026-08-01&to=2026-08-13" \
  -H "Authorization: Bearer $TOKEN"

POST /api/stats/clear 清空阅读明细日志（不可恢复）， 对应后台仪表盘的「清理阅读日志」。

访问分析：/api/analytics

GET /api/analytics 返回访问分析各维度：独立访客与 新老客、设备/浏览器/系统构成、来源域名与路径明细、搜索关键词、时段热力、 站内互链、单篇来源下钻、实时访问流。可选查询参数 from/to （格式 YYYY-MM-DD，站点时区日期边界）。对应后台「访问分析」页。

curl "{{ api_base }}/api/analytics?from=2026-08-01&to=2026-08-13" \
  -H "Authorization: Bearer $TOKEN"

口径说明：本接口所有面向读者的指标默认剔除爬虫 （device = 'bot'）——搜索引擎爬虫每日抓取会让原始 PV 虚高数倍； 爬虫量单独放在 summary.bot_views 里，不混入阅读统计。

站点设置：/api/settings

GET /api/settings 返回全部站点设置键值。 PATCH /api/settings 局部更新，只接受白名单键：site_name、 site_desc、site_nav、site_social、 social_logos、site_logo、footer_text、 friend_links、contact_enabled、contact_email； 未传的键保持不变，返回更新后的全量设置。校验规则与后台设置页一致。

curl -X PATCH {{ api_base }}/api/settings \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"site_name":"寒蝉","site_desc":"一个人的独白"}'

系统设置：/api/system

GET /api/system 读取系统设置； PATCH /api/system 局部更新，白名单键：theme_mode （auto|light|dark）、timezone （IANA 名，如 Asia/Shanghai）、date_format （datetime|date）。改管理员密码仍走后台。

主题：/api/themes

方法路径说明
GET/api/themes已安装主题列表 + 当前主题
POST/api/themes/import上传主题 zip 安装（multipart 字段名 theme）
POST/api/themes/{name}/activate把主题设为当前（重启后完全生效）
DELETE/api/themes/{name}卸载主题（204，不许卸载当前使用中的）

徒步轨迹：/api/trails

方法路径说明
GET/api/trails轨迹列表（里程/爬升/时长等统计）
POST/api/trails/import上传 GPX 导入（multipart 字段名 files，可选 name/description）
GET/api/trails/{id}轨迹详情（?with_coords=1 附完整坐标）
PATCH/api/trails/{id}更新名称/描述（缺失字段不变）
DELETE/api/trails/{id}删除轨迹（204，清理 GPX + 坐标）

列表返回 {data: {items: [...], total}}，详情字段含 started_at、distance_km_str、elevation_gain_str、 moving_time、point_count 等展示统计； ?with_coords=1 时附加 coords（[[lat, lon, speed], ...]）。 导入返回 {data: {imported: [...], imported_count, errors: [...]}}。

备份：/api/backup

全量备份 zip 下载（数据库 + 配置 + 上传 + 主题）， Content-Type: application/zip。适合 CI / 运维脚本定时拉取。

curl -o backup.zip {{ api_base }}/api/backup -H "Authorization: Bearer $TOKEN"

健康检查：/api/health

存活探针，无需鉴权。返回 {"data": {"status": "ok"}}。

MCP 集成（AI 工具）

本博客的 REST 接口已包装为 48 个 MCP 工具，供 Claude Code / Codex / Kimi Code 等 AI 客户端直接调用—— 让 AI 能查文章、发文章（含独立页面）、写说说、管理分类/标签/专栏、上传附件、 调站点/系统设置、管理主题与轨迹、下载备份，无需手写 HTTP 请求。

接入方式一（推荐，集中托管）：若已自建 hancic-mcp-server，客户端只填一个 URL + Basic 凭据，无需本机装 Python：

{
  "mcpServers": {
    "hancic": {
      "type": "http",
      "url": "https://mcp.hancic.site/hancic/mcp",
      "headers": { "Authorization": "Basic <base64(mcp:密码)>" }
    }
  }
}

接入方式二（本机 stdio）：在本机安装依赖并确认环境变量：

cd mcp && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
# 环境变量
HANCIC_API_TOKEN=本页生成的 Token
HANCIC_BASE_URL=https://hancic.site   # 反向代理场景填代理后的公开地址（含子路径）

接入 Claude Code：

claude mcp add hancic -- \
  env HANCIC_API_TOKEN=你的token HANCIC_BASE_URL=https://hancic.site \
  python /path/to/hancic-blog/mcp/hancic_mcp.py

接入 Codex / Kimi Code：在客户端 MCP 配置（或项目级 .mcp.json）注册同一命令：

{
  "mcpServers": {
    "hancic": {
      "command": "python",
      "args": ["/path/to/hancic-blog/mcp/hancic_mcp.py"],
      "env": {
        "HANCIC_API_TOKEN": "你的token",
        "HANCIC_BASE_URL": "https://hancic.site"
      }
    }
  }
}
