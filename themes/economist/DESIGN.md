# Design: Broadsheet editorial（《经济学人》式大报排版）

一句话：把博客读成一份报纸——密集的栏、锐利的分隔线、一个红色方块报头，其余全是字。

> 本文件是 `themes/economist` 的呈现契约，只约束本主题；后台与其它主题各自独立。

## 为什么是这个方向

博客默认形态是「卡片流」，而《经济学人》的说服力来自**版式本身**：栏宽、栏距、字号级差和一条红线。
用户是长文读者，要的是「一进来就像在读报」的密度与秩序感，所以取 **Swiss/editorial** 方向的具体印刷变体，
而不是泛化的「干净现代」。

## Palette（1 色相 + 暖中性阶）

- 主面（约 60%）：`#FBFAF7` 纸白（暖白，非纯白）
- 次面（约 30%）：`#F2EEE6` 纸灰面板 / `#E8E3D8` 深一档，用于「数据框」
- 文字阶：`#1A1815` 墨 → `#45403A` 次墨 → `#6B6459` 元信息
- 唯一强调色（≤10%）：`#E3120B` 报头红（版面填充、栏线、活跃态）
  - 小字用同色相深一档 `#B3120C`（保证小字号对比度）
  - 报头红块在暗色模式下降为 `#C21F14`（白字对比度仍 ≥ 5.9:1）
- 分隔线：强线 `#1A1815`（3px 栏头）、细线 `#D9D3C7`（条目间）、发丝线 `#E6E0D4`
- 暗色为「夜版印刷」：`#14120F` 纸底 / `#ECE7DD` 墨 / `#FF4B3E` 红（暗色下红色降饱和提亮）
- 语义色不引入：本主题无状态语义，仅有链接/点赞两种交互态

## Type

- 标题（Display）：系统无衬线栈 `-apple-system / Segoe UI / PingFang SC / Hiragino Sans GB / Microsoft YaHei / Noto Sans SC`——中文环境里唯一体面且免费的无衬线；字重只用 600/700，靠**字号与栏宽**而非字族制造个性
- 正文（Body）：`Georgia / Times New Roman / Songti SC / SimSun / Noto Serif SC`——拉丁走 Georgia、中文走宋体，贴合《经济学人》正文的低对比衬线
- 数据/代码：`ui-monospace / SFMono-Regular / Menlo / Consolas`
- 尺度比 1.333（编辑体）：16 / 21 / 28 / 38 / 50 / 67
  - 正文 17px / 行高 1.78；文章 H1 `clamp(1.75rem, 1.15rem + 2.6vw, 2.85rem)`，行高 1.12，字距 -0.02em
  - 元信息 12–13px / 行高 1.5；表格与统计数字一律 `font-variant-numeric: tabular-nums`
- 行宽：正文栏 `max-width: 40em`（中文约 38–40 字/行）；列表摘要 3 行截断
- 标题 `text-wrap: balance`，正文段落 `text-wrap: pretty`；正文不两端对齐（避免中文空洞）

## Form

- 圆角：**0**。全主题无圆角（印刷品没有圆角）
- 间距：4px 网格（8px 基数），区块间距 32 / 40 / 56
- 阴影：**无**。层级只靠「留白 → 纸面色差 → 分隔线」三级递进，描边永远是最后手段
- 边框：细线仅用于条目分隔；区块头用 3px 强线；数据框用「2px 强上边线 + 纸灰底」，不用四边描边
- 卡片：不存在。栏目（zone）与条目（item）是版面单位，不是容器

## Motion

- 人格：印刷品＝静止。只保留 120ms 的悬停态反馈（颜色/下划线），不做入场动画、不做视差
- 列表滚动淡入（`main.js` 的 `.reveal`）在本主题**不启用**——报纸不做逐条飞入
- `prefers-reduced-motion: reduce` 全局降级

## 这套设计**不**使用

- 圆角卡片、投影、玻璃拟态、渐变文字、紫→蓝渐变
- 居中 Hero、悬浮药丸徽章、三卡并排模板、三段式落地页
- 正文两端对齐、图标当装饰、emoji
- 悬浮球形工具组（明暗切换归入报头工具条，回顶归入页脚）
- 多于一个强调色相；英文全大写标签（中文排版靠字距与红方块，不靠大写）

## 可访问性底线

- 正文/标题对比度全部实测（WCAG ≥ 4.5:1，小字红 ≥ 6.7:1）
- `:focus-visible` 2px 红描边；所有交互元素有 hover / focus-visible / active 态
- 正文 ≥ 16px、行宽 ≤ 75ch；表格数字等宽
- 键盘可达：导航下拉支持移动端点击展开，`aria-expanded` 同步
